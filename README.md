# FinalLIS4370


FinalLIS4370 is a personal finance tracker I created. This R package is designed to help users manage their personal finances. The package allows users to track expenses, through either manually uploading them or uploading them through a spreadsheet. It's an easy-to-use tool for those looking to gain insight into their spending habits and better manage their finances.

## Features

- Add Expenses: Add expenses manually
- Import Expenses: import them from CSV or Excel files.

## Installation

To install the development version of **PersonalFinanceTracker** from GitHub, install the `devtools` package
